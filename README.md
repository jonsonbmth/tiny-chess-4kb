A 4 KB chess engine: alpha-beta search with quiescence, transposition table
and tapered king evaluation, plus a precomputed book of winning lines for the
practice gauntlet. Plays through the env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
